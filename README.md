# Reddy's Meals & Curry Point Website

Official responsive web application for **Reddy's Meals & Curry Point**, located in Santhi Nagar, Uppal, Hyderabad.

## Features
- **Apple iPhone Liquid Glass UI**: Modern aesthetic with fluid gradients, backdrop blurs, and micro-interactions.
- **Dynamic Daily Menu**: Interactive category filter (All, Available Today, Meals, Curries, Biryani) with real-time availability tags.
- **Bulk Pre-Bookings**: Clear ordering flow for group meals (20–100 members).
- **Direct Calling**: One-tap phone call buttons for primary and secondary contact numbers.
- **Location & Navigation**: Official embedded Google Maps pin and direct navigation buttons for Google Maps & Apple Maps.
- **Zero Dependencies**: Pure HTML5, Vanilla CSS3, and JavaScript.

## Local Development
Run any static server or double-click `index.html`:
```bash
npx serve . --listen 3000
```
